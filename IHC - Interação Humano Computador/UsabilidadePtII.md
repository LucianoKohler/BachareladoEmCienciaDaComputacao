# TICs
- Tecnologias da Informação e da Comunicação
- Se tornaram parte vital para TUDO
    - Comércio
    - Saúde
    - Lazer
    - Etc...
- TICs muitas das vezes são feitos com um objetivo em mente, porém nem sempre essa tarefa é feita da forma mais clara para o usuário (seja por corte de gastos ou até mesmo preguiça das criadoras das tecnologias)

A **IHC** se importa com a comunicação "de fora pra dentro", ou seja, o foco dela é o de como o meio externo (usuários) interage e acessa o meio interno do sistema (seus dados), o lado contrário ("de dentro pra fora"), é mais analisado pela **Engenharia de Software** (como transmitir os dados da melhor forma para o usuário)

Para criar softwares que condizem com os ideais da IHC, é importante, primeiramente, definir como o software deve agir com o usuário

## Perspectivas de interação
- Formas que um software se comporta
    - **Sistema**: Máquina feita para conversar com outra máquina
    - **Parceiro de discurso**: Máquina imita o comportamento humano para criar um contato mais humano
    - **Ferramenta**: Máquina feita para disponibilizar uma interface para modificar e criar arquivos
    - **Mídia**: Máquina feita para intermediar a comunicação entre duas pessoas

Professor falou sobre o **Esqueumorfismo**, uma técnica de criação de software que tenta ao máximo assemelhar seu uso com o da vida real (tipo usar um ícone de lixeira para apagar um arquivo), um GRANDE exemplo disso é o **Microsoft Bob**
