# Design de Interação
É um desenvolvimento focado em como o aplicativo/website será utilizado pelo usuário, tentando maximizar a boa experiência para os usuários, seguindo alguns **princípios de design**: 

## Princípios de Design
- **"do"s and "don't"s**: Resumidos em
    - Requisitos **necessários**: Exemplo **RFs** e **RNFs** de SOFT
    - Requisitos **desejáveis**: Exemplo **modo noturno** no site
    - Requisitos **não-desejáveis**: Exemplo usar cores muito incoerentes com o site

- **Visibilidade**
    - Visão é o mais importante dos 5 sentidos ao travegar um app, logo ter uma boa visibilidade é crucial
        - Usar cores **corretas e coerentes**
        - Dar **feedback visual/sonoro/tátil** ao executar uma ação (uma boa prática é dar DOIS feedbacks para garantir caso um deles falhe)

- **Constraints/Restrições** (tem 3 tipos)
    - **Físicas:**
        - Impedir o usuário de cometer equívocos via hardware
        - Exemplo: Impedir o usuário de colocar um CD de ponta-cabeça no toca-discos
        - Impedir só com rótulos de aviso **não é uma boa ideia**
    - **Culturais:**
        - Alguns símbolos são **interpretados diferentemente em diferente culturas**, como por exemplo o Japão, que lê da direita para a esquerda, "invertendo" instruções
        - Outros símbolos são universais, como por exemplo a **lata de lixo = apagar algo**
    - **Lógicos:**
        - Mapear botões ou instruções **de forma lógica**, como por exemplo, botões de um tocador de discos (**retroceder, pausar, pular = vai pra trás, para, vai pra frente**)
- **Consistência**
    - **Seguir padrões**, seja por:
        - **Atalhos do teclado**
        - **Cores** em um site
        - **Uso de logomarcas**
        - **Localização dos botões**
    - tudo deve ser **consistente**
- **Atividade**
    - O quão **atrativo** (ou **não atrativo**) é algo para o usuário
        - Botões de fechar anúncio pequenininhos dificultam fechar ele
        - Botões grandes de play induzem o usuário à escutar música
- **Affordances**
    - Elementos tem que fazer a função que serve para eles
        - Botões não devem mostrar informações que um texto descritivo deveria
        - Textos não devem ser clicáveis (a menos que especificados)
